# Hazır 3D İç Aksesuar Modelleri (`.glb`)

Birim Configurator, gardırop iç aksesuarları (ceket, gömlek, ayakkabı, katlı kumaş, çanta/puf, gözlük ve saat) için prosedürel el çizimi yerine gerçek 3D taranmış / modellenmiş `.glb` dosyalarını (`GLTFLoader` + `DRACOLoader`) yükler ve otomatik olarak milimetre (`mm`) dolap ölçülerine ölçekler.

Varsayılan olarak açık kaynak 3D model depolarından (Khronos Group `glTF-Sample-Assets` ve GitHub glTF/GLB depoları) doğrudan yüklenir. İsterseniz Poly Haven, Sketchfab veya BlenderKit üzerinden indirdiğiniz kendi `.glb` dosyalarınızı arayüzdeki **3D İç Aksesuar Kütüphanesi (.GLB)** penceresinden seçebilir ya da bu klasöre koyabilirsiniz:

- `jacket.glb` — Askılı ceket / palto
- `shirt.glb` — Askılı gömlek / üst giyim
- `shoe.glb` — Raflı / eğimli ayakkabılık modeli
- `folded_cloth.glb` — Katlı kazak / tekstil istifi
- `silk_pouf.glb` — Dolap içi çanta / düzenleyici kutu / puf
- `sunglasses.glb` — Açık raf / aksesuar gözlüğü
- `watch.glb` — Kronograf kol saati
